# EGFR AI Predictor & Bioinformatics Dashboard

An interactive machine learning and bioinformatics web application designed to predict compound bioactivity against the Epidermal Growth Factor Receptor (EGFR) for targeted computational drug discovery.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://gunjanbhardwaj14-egfr-ai-predictor-app-2iqcps.streamlit.app/)

🔗 **Live Demo:** [Open EGFR AI Predictor Web App](https://gunjanbhardwaj14-egfr-ai-predictor-app-2iqcps.streamlit.app/)

---

## Project Overview
- **Target:** Human Epidermal Growth Factor Receptor (EGFR), an established oncology target.
- **Workflow:** Automated data collection, chemical descriptor calculation, bioactivity classification/prediction, and interactive model inference.
- **Dashboard Interface:** Built using Streamlit to provide real-time compound predictions and structural bioactivity insights.

---

## Tech Stack & Libraries
- **Bioinformatics & Chemistry:** BioPython, RDKit / PubChem data retrieval
- **Machine Learning & Modeling:** Scikit-Learn, Pandas, NumPy
- **Application & UI:** Streamlit
- **Environment:** Python 3.10+
